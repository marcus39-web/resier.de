# Release Checkliste

## Inhalt

- Headline und Kurzprofil auf Zielrolle abgestimmt
- Zertifikate mit echten Namen, Datum und Nachweis-URL eingetragen
- Projekttexte nach Schema Problem, Loesung, Lerngewinn formuliert

## Technik

- Alle PHP-Dateien ohne Syntaxfehler: php -l
- Kontaktformular getestet (Erfolg und Validierungsfehler)
- Links auf Startseite, Portfolio und Kontakt geprueft
- Mobil und Desktop kurz visuell geprueft

## Git

- Aenderungen mit klarer Commit-Message committen
- Push auf main erfolgreich
- Repo-Beschreibung und Readme aktuell halten
